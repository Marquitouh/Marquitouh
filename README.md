<h2 align="center">· Sobre mí ·</h2>

<img src="https://raw.githubusercontent.com/Marquitouh/marquitouh.github.io/main/assets/pixelfox-icon.png" alt="PixelFox Studios" width="240" align="right" />

Desarrollador de software y estudiante de diseño de videojuegos. Me apasiona
crear experiencias interactivas donde el código estructurado, la arquitectura
limpia y el arte convergente se unen para que las cosas no solo funcionen, sino
que realmente se sientan bien al usarse.

Mi enfoque principal está en el desarrollo con `Unity` (`C#`), donde trabajo
aplicando patrones de diseño para construir sistemas escalables y mecánicas
fluidas, el desarrollo web (`HTML`, `CSS`, `JavaScript`) para crear interfaces
intuitivas, y la dirección visual (pixel art y diseño conceptual).

Creo que un buen proyecto nace del equilibrio entre una lógica impecable y una
estética con personalidad. Siempre explorando nuevas herramientas, puliendo
detalles y transformando ideas en proyectos tangibles.
